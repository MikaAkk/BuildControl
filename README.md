# BuildControl
Дипломная работа
**Автоматизированная система управления строительными проектами и взаимодействия с клиентами.**

«СтройКонтроль» — это веб-платформа, объединяющая публичный портал для клиентов, корпоративный портал для сотрудников и административную панель для руководства. Система призвана устранить хаос в управлении стройплощадками, автоматизировать распределение задач и сделать процесс строительства прозрачным для всех участников.

Основная цель проекта — цифровизация жизненного цикла строительного объекта: от первого контакта с клиентом до сдачи объекта в эксплуатацию.

Система разделена на три изолированные зоны доступа с разными уровнями прав.

### 1. Публичный портал (Клиентская часть)
Открытая зона для потенциальных заказчиков.
*   **Каталог услуг и Калькулятор:** 
*   **Портфолио и Отзывы:**
*   **Заявка на консультацию:** 
*   **Статус доступа:** Только чтение + отправка форм.

### 2. Корпоративный портал (Внутренняя часть)
Защищенная зона для сотрудников компании. Доступ по логину/паролю.
| **Сотрудник ** | Видит только свои объекты и персональные задачи. Может отмечать задачи как «Выполнено». Не видит финансовую информацию и других сотрудников. |
| **Руководитель** | Полный доступ к своим объектам. Может создавать объекты, назначать сотрудников, ставить задачи, менять статусы объекта, общаться с клиентом. Имеет права сотрудника + управленческие функции. |

### 3. Административный портал (Админ-панель)
Зона высшего уровня доступа для директора или системного администратора.
*   **Управление пользователями:** Создание, блокировка, смена ролей и паролей для всех сотрудников.
*   **Управление контентом:** Редактирование каталога услуг, прайс-листов.
*   **Общий контроль:** Сводная аналитика по всем объектам компании, загрузка сотрудников, мониторинг активности.
*   **Распределение заявок:** Ручное назначение входящих заявок на свободных руководителей объектов.

## Процесс 

Типичный сценарий работы в системе:
1.  **Контакт:** Клиент заходит на публичный сайт, использует калькулятор и оставляет заявку на консультацию.
2.  **Назначение:** Администратор видит новую заявку в админ-панели и назначает её на свободного Руководителя объекта подходящей специализации.
3.  **Старт проекта:** Руководитель связывается с клиентом, заключает договор и создает в системе карточку нового «Объекта».
4.  **Планирование:** Руководитель назначает на объект Сотрудников и ставит им конкретные задачи с дедлайнами.
5.  **Исполнение:** Сотрудники заходят в систему со своих устройств, видят список задач и отмечают их выполнение по мере работы.
6.  **Контроль:** Статус объекта автоматически обновляется. Руководитель и Администратор видят полную историю изменений и текущий прогресс.
